# Emmanuella Pelumi Birthday Website

A mobile-friendly interactive birthday surprise in pink and black.

## Included features

- Animated opening screen
- Emmanuella Pelumi's name and July 17th
- Responsive photo gallery
- Click-to-reveal compliments
- Interactive birthday letter
- Optional background music
- Birthday wish button with confetti
- No framework or installation required

## Add Emmanuella's real pictures

Open the `assets` folder and replace:

- `precious-1.jpg`
- `precious-2.jpg`
- `precious-3.jpg`
- `precious-4.jpg`
- `precious-5.jpg`
- `precious-6.jpg`

Keep the same filenames so the website updates automatically.

The first picture is also used as the large background image on the welcome page.
A portrait image works best.

## Add her favourite song

Place an MP3 file inside the `assets` folder and name it:

` song.mp3 `

Browsers do not allow music to start automatically, so she must tap the
"Play Music" button.

## Preview the website

The easiest method:

1. Open the project folder.
2. Double-click `index.html`.
3. It will open in your browser.

You can also use VS Code's Live Server extension.

## Change the messages

Edit the words directly inside `index.html`.

The compliment cards are under:

`Reasons You Are Amazing`

The birthday letter is under:

`Dear Emmanuella`

## Put it online for free
